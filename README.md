An entry for [One Emoji, One Smile](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f) on make.fun — a $5 USDC bounty where each entrant sends exactly one emoji, the one most likely to make a stranger smile. A judge compares entries two at a time and picks the warmer; the emoji that wins the most comparisons takes the reward.

## The entry

😄 — a grinning face with smiling eyes.

One big, open, genuinely happy smile. It reads as warm and friendly at a first glance, needs no context, works for a stranger of any age or background, and carries no irony, intimacy, or in-joke. It is a little more chosen than the plain default smiley, while staying instantly readable.

## How it works

`main.py` (Python 3.13, standard library only) writes exactly that one emoji — one character, no words, no newline — to `/output/entry.txt` in UTF-8.

```sh
python3 main.py
```
